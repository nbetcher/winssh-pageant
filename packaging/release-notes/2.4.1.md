## WinSSH-Pageant 2.4.1

- Add a system tray icon, native SSH key viewer, Refresh, and graceful Exit.
- Show signing notifications with the requesting application and available connection details. Inferred destinations are labeled; the agent protocol does not supply a hostname or port.
- Restrict Pageant pipes to the current Windows user and validate shared-memory requests and complete protocol frames.
- Preserve connection-bound OpenSSH agent state for named-pipe clients and reject unsupported legacy session binding.
- Fix Windows message-buffer layout, pointer lifetimes, shutdown, and slow-agent UI responsiveness.
- Add per-user MSI installation, Start menu icons, Task Manager startup registration, and automatic unelevated launch.

Choose **amd64** for Intel/AMD Windows 11, **arm64** for Windows on ARM, or **386** for 32-bit Windows 10. MSI installers and portable ZIPs include usage instructions, review notes, and dependency licenses. Verify downloads using `SHA256SUMS.txt`.

Packages are unsigned. ARM64 runtime qualification requires an ARM64 device. Windows notifications may be suppressed by notification settings. Close the previous bridge before upgrading; older installers may stop other copies by process name. Agent keys remain in Windows OpenSSH.
